# 盯盘管家 Tauri 版验收方案

日期：2026-11-12

目标是在 Windows 和 macOS 上交付可独立构建的开源桌面端，迁移现有盯盘流程，在应用内绘制 K 线，并实测安装包及盘中常驻开销。

## 功能验收

| 编号 | 操作 | 通过条件 |
| --- | --- | --- |
| F1 | 首次安装、登录、切换账号并重启 | 账号隔离，登录状态按预期恢复。旧版用户可迁移窗口和快捷键设置，登录凭据的处理方式有文档 |
| F2 | 打开自选、切换分组、添加、删除和置顶 | 结果与旧版业务一致。标准和精简布局可切换，快速切组时旧订阅的数据不会覆盖当前组 |
| F3 | 接收实时行情，模拟断线并恢复 | 报价正确更新，重连后无重复订阅，行情中断时可识别状态 |
| F4 | 点击系统最小化和关闭按钮，再用托盘和全局快捷键唤出 | 最小化遵循系统行为，关闭隐藏窗口并保留托盘。行情持续更新，托盘报价一致，可恢复窗口和焦点。验证窗口置顶、透明度、快捷键冲突、显式退出 |
| F5 | 打开个股 K 线，切换股票和周期 | 图表由本地资源绘制，无外链导航。用固定 OHLCV 样本核对蜡烛、成交量、均线、时区和交易日。验证缩放、拖动、十字线、空数据和接口失败 |
| F6 | 检查历史行情和实时行情的交接 | 明确行情来源和数据使用条件。通过固定样本验证历史加载和最新一根蜡烛更新，再验证真实接口 |
| F7 | 验证应用更新与退出 | 明确旧版到新版的安装方式。启用自动更新时验证签名、损坏包拒绝和数据保留 |

## 原生窗口验收

在 macOS 和 Windows 各运行一次 Release 应用，记录系统版本和每项结果。

1. 从系统标题栏拖动主窗口，检查标题只出现一次。Mac 检查左上角原生窗口按钮，Windows 检查右上角原生窗口按钮。
2. 点击系统最小化按钮，分别从 Dock 或任务栏恢复，确认自选分组和图表周期仍保留。
3. 点击系统关闭按钮，确认主窗口隐藏且托盘仍在。先从托盘显示主窗口，再关闭一次并用已配置的全局快捷键唤出，检查窗口获得焦点。
4. 使用真实行情账号打开自选，在有更新的时段重复第 3 步，确认托盘报价在隐藏期间继续更新。
5. 从托盘选择「退出管家」，确认应用和托盘入口退出。重新启动后检查设置恢复。

`npm run test:e2e` 可重复验证应用内页面和行情链路。系统标题栏、Dock、任务栏和托盘按本节实机验收。

## 双端安装与性能

- Windows 10/11 x64 和 macOS Apple Silicon 真机各走一遍安装、启动、退出、重装。Windows 验证 WebView2 缺失时的补装。若发布 Intel macOS 或 Windows ARM64 产物，各自单独验收。
- 同机分别运行 Electron 旧版和 Tauri release 版，记录系统版本、CPU、内存、架构、构建提交和行情样本。旧版 Windows 安装清单为 83,196,610 字节。新包的暂定目标为 Windows 联网安装包及 macOS 单架构 DMG 各低于 20 MB。
- 记录冷启动到首条有效报价的时间，各运行五次，比较中位数。
- 用同一份自选数据和行情回放，以相同的更新频率测试空闲和隐藏到托盘持续收行情两种场景。每种预热两分钟后采样十分钟，记录平均 CPU 和常驻内存中位数，覆盖应用及其可归属的 WebView 进程。目标为两端常驻内存较旧版下降、CPU 无明显回退。记录窗口唤出延迟及多次开关 K 线后的内存变化。
- 用同一份历史行情和相同画面范围重复测试缩放、拖动和十字线，记录帧耗时 P50/P95。以 60 Hz 下常见操作 P95 接近或低于 16.7 ms 为目标。旧版使用外部 K 线页，仅作为参考，记录数据量和功能差异。

## 开源交付

- 保留原项目适用的 LICENSE 和版权声明，核对迁入代码、图标、字体、图表库及行情数据的许可与署名。开源源码和分发第三方数据分别核对。
- 新仓库从空目录安装依赖后可以使用公开文档构建。提交锁文件、示例配置和可离线运行的行情样本。
- 检查发布树和提交历史，排除真实账号、令牌、私钥、私有配置、用户数据以及未经核准的第三方资源。真实接口与样本模式可独立配置。
- 签名、macOS 公证、更新签名和公开仓库发布分别记录验证结果。发布前提供安装产物、双端测试结果与已知限制。回退时可继续使用旧版安装包，设置迁移先保留源文件。
