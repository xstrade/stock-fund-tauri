# 迁移说明

旧工程的 Electron 主进程与渲染进程通过 IPC 交互。新版把窗口、托盘、快捷键和桌面权限放入 `src-tauri`，Vue 调用范围固定的桌面命令。自选列表和 K 线共享同一个窗口，K 线组件在打开时加载，返回自选时释放图表实例。

| 原功能 | 新版实现 | 验收状态 |
| --- | --- | --- |
| 登录、切换账号 | 旧版账号接口适配，会话通过系统凭据存储按服务隔离 | 模拟通过会话恢复、过期与退出清除。待用真实账号和系统凭据存储联调 |
| 自选分组、搜索、增删及置顶 | 复用旧版业务字段和接口格式，保留离线自选样本 | 离线可运行，真实写入待授权验证 |
| 自选实时行情 | SSE 按交易市场和代码索引更新，切组取消旧连接，重试断开连接 | 待验证真实 SSE 传输和异常恢复 |
| 标准和精简列表、透明度、置顶、托盘、快捷键 | Vue 设置与 Tauri 窗口管理，可手动导入旧版设置文件 | 待双端真机验证 |
| 外部 K 线页和自选内分时缩略图 | 内置分时、日 K、周 K、月 K、均线、成交量、十字线和缩放，直连东方财富历史行情接口，图表打开时轮询更新，标准列表分时缩略图只在可见时加载 | 缩略图离线和模拟通过，真实历史行情及最新蜡烛更新待验 |
| 旧版自动更新 | 首次独立安装，后续启用签名更新，默认离线安装包关闭更新源 | 前端模拟通过，正式更新源、原生签名安装及公证待验 |

开源发布前核对真实数据源的使用条件。发布物使用默认的离线配置，凭据、历史用户数据与打包签名均由发布环境管理。
